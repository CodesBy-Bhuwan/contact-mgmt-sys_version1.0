# 🚀 Full-Stack Application

A full-stack web application built with **Java Spring Boot** and **React.js**, featuring REST APIs and database integration with MySQL and SQLite.

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, REST API
- **Frontend:** React.js, JavaScript, HTML, CSS
- **Databases:** MySQL, SQLite
- **Tools:** Maven, Git, GitHub

## ✨ Features

- RESTful API development using Spring Boot
- Interactive and responsive React.js frontend
- MySQL integration for persistent data storage
- SQLite support for lightweight, local database storage
- Frontend and backend communication through HTTP requests

## 🏗️ Architecture

```text
React.js Frontend
       │
       ▼
  REST API
       │
       ▼
Spring Boot Backend
       │
       ├── MySQL
       └── SQLite
```

## ⚙️ Getting Started

1. Clone the repository.
2. Configure database connections in `application.properties`.
3. Start the Spring Boot backend.
4. Install frontend dependencies using `npm install`.
5. Run the React application using `npm run dev`.
